# CodeAlpha Full Stack Development Tasks

Two independent full-stack project implementations using **React + Vite, Node.js, Express, and MongoDB**:

1. `CodeAlpha_EcommerceStore` — products, JWT authentication, cart, order creation, order history.
2. `CodeAlpha_ProjectManagementTool` — projects, task cards, task status, comments, JWT authentication.

## Requirements
- Node.js 18+ (Node.js 20+ recommended)
- npm
- MongoDB local instance or MongoDB Atlas connection string
- Git and GitHub account for publishing

Each project has its own backend and frontend. Read its README for setup instructions.

## Important
These are internship-ready MVPs intended for learning and extension. Configure your own MongoDB URI and JWT secret, run both applications locally, test the flows, and add screenshots/demo video before submitting. Never commit `.env` files or real credentials.

## Suggested completion workflow
1. Start and test the backend.
2. Start and test the frontend.
3. Test registration/login and the main project features.
4. Update each README with your own screenshots and demo video link.
5. Push each folder to a separate GitHub repository using the exact names requested by CodeAlpha:
   - `CodeAlpha_EcommerceStore`
   - `CodeAlpha_ProjectManagementTool`
6. Submit the repository links through the CodeAlpha submission form shared with your group.
